# 📋 RECTO : LE PROTOCOLE TERRAIN & LE RECUEIL sRPE

```
+-----------------------------------------------------------------------------------+
|  ⏰ RÈGLE D'OR N°1 : LE TIMING DES 20-30 MINUTES                                   |
|  Ne JAMAIS faire noter les joueurs au coup de sifflet final !                      |
|  Attendre 15 à 30 minutes (au vestiaire ou après la douche).                       |
|  Raison scientifique : Éviter le biais de récence (un joueur ayant fini par un     |
|  décrassage doux sous-estimera une séance pourtant très éprouvante).               |
+-----------------------------------------------------------------------------------+
|  🤫 RÈGLE D'OR N°2 : CONFIDENTIALITÉ ABSOLUE (ZÉRO MOUTONNERIE)                   |
|  Le joueur note SEUL sur le smartphone/tablette (Mode Borne PIN ou Coach Direct).  |
|  Interdiction formelle de crier sa note à haute voix devant les coéquipiers.       |
|  Raison scientifique : Éliminer le mimétisme social et la fausse virilité.        |
+-----------------------------------------------------------------------------------+
|  🔄 RÈGLE D'OR N°3 : RÉGULARITÉ & RIGUEUR DU MICROCYCLE                            |
|  Noter TOUTES les séances (entraînements, matchs amicaux, compétitions officielles)|
|  L'algorithme ACWR exige une continuité temporelle pour être fiable.              |
+-----------------------------------------------------------------------------------+
```

## 💤 QUESTIONNAIRE BIEN-ÊTRE HOOPER (AVANT LA SÉANCE)
*Recueil de 4 items notés de 1 (Optimal) à 5 (Très Mauvais) :*

```
1. SOMMEIL     : [1: Excellent]  [2: Bon]     [3: Moyen]     [4: Mauvais]   [5: Nuit Blanche / الأرق]
2. COURBATURES : [1: Aucune]     [2: Faible]  [3: Modérée]   [4: Forte]     [5: Très Douloureux / كراش]
3. FATIGUE     : [1: En forme]   [2: Normale] [3: Fatigué]   [4: Épuisé]    [5: Exténué / ميت عيا]
4. STRESS      : [1: Très calme] [2: Normal]  [3: Préoccupé] [4: Anxieux]   [5: Stress Maximal / ضغط]
```
*👉 **Alerte Coach** : Si le total Hooper $\ge 15/20$ ou si le Sommeil $= 5$, individualiser la séance (décharge).*

# 📋 VERSO : GUIDE DÉCISIONNEL DU COACH (ACTION MATRIX)

## 🚦 MATRICE DES ZONES ACWR (TIM GABBETT)

```
        ACWR (Charge Aiguë 7j / Charge Chronique 28j Uncoupled)
 [ < 0.80 ]   ------>   SOUS-CHARGE (Sous-entraînement, risque de désadaptation)
 [0.80 - 1.30] ------>   SWEET SPOT (Zone optimale de progression & protection)
 [1.30 - 1.49] ------>   ZONE VIGILANCE (Surveillance accrue de la fatigue)
 [ >= 1.50 ]   ------>   ZONE ROUGE DANGER (Risque de blessure multiplié par 2 à 4)
```

---

## 🚨 ARBRE DÉCISIONNEL D'URGENCE : JOUEUR EN ZONE ROUGE (ACWR $\ge 1.5$)

Quand un joueur titulaire clé passe en **Zone Rouge**, voici la conduite à tenir :

```
                 LE JOUEUR EST EN ZONE ROUGE (ACWR >= 1.50)
                                      |
                 +--------------------+--------------------+
                 |                                         |
     Hooper Normal (< 12)                        Hooper Mauvais (>= 12)
                 |                                         |
    [SURVEILLANCE ACTIVE]                     [INTERVENTION IMMÉDIATE]
  - Participe à l'entraînement             - Retirer des blocs de VMA / Sprints
  - Écourter les blocs de jeux réduits      - Remplacer par travail tactique passif
  - Réduire le match du WE à 60' max        - Décrassage, étirements, hydratation
                                            - Limiter le match du WE à 30-45'
```

## 📈 MONOTONIE & STRAIN : QUAND S'INQUIÉTER ?

* **Monotonie $> 2.0$** : Attention danger ! Les séances sont toutes de même intensité sans vraie séance légère ou jour de repos.  
  👉 **Action** : Insérer immédiatement un jour de repos complet ou une séance ludique / récupération technique.
* **Strain Élevé** : Produit d'une grosse charge hebdomadaire et d'une forte monotonie.  
  👉 **Risque** : Chute immunitaire, baisse de performance et claquages musculaires (ischio-jambiers / quadriceps).

## 🇩🇿 SPÉCIFICITÉS DU TERRAIN DE FOOTBALL EN ALGÉRIE

1. **🏟️ Terrains Synthétiques (Tartan / 5G sablé)** :
   * Les synthétiques algériens durcissent sous l'effet du soleil et de l'usure.
   * L'impact articulaire et la fatigue excentrique des adducteurs/mollets augmentent de **20 à 30%**.
   * *Consigne : Dès que le RPE moyen de l'équipe dépasse 7 sur synthétique, écourter la durée de 15 minutes.*

2. **☀️ Fortes Chaleurs (Hauts-Plateaux & Sud)** :
   * La déshydratation gonfle artificiellement la perception de l'effort cardiorespiratoire.
   * *Consigne : Multiplier les pauses boisson (cooling breaks) toutes les 15 minutes.*

3. **📚 Périodes Scolaires (BEM / Baccalauréat) & Ramadan** :
   * Le stress scolaire et le manque de sommeil font chuter la tolérance à la charge.
   * *Consigne : Activer le questionnaire Hooper systématiquement avant la séance pour adapter les volumes.*
